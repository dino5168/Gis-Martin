# 6. 前後端分離：Cloudflare 前端 + 本機後端（實作計畫）

> 需求：[6-前後端分離.md](6-前後端分離.md)。前端放 Cloudflare，本電腦當圖磚後端。
> 建立日期：2026-11-17

## 1. 架構

```
瀏覽器
  │ ① https://map.<domain>/            （靜態檔：index.html、JS、worker）
  ▼
Cloudflare Pages（web/dist，由 GitHub dino5168/Gis-Martin 自動建置）

瀏覽器
  │ ② https://tiles.<domain>/land,…,pois/{z}/{x}/{y}
  ▼
Cloudflare Edge（Cache Rule 快取圖磚、WAF 限流）
  │ Cloudflare Tunnel（本機主動連出，不開任何對外 port）
  ▼
本電腦：cloudflared（Windows 服務）──▶ Martin 127.0.0.1:3000 ──▶ PostGIS
```

設計決策：

| 項目 | 決定 | 理由 |
|---|---|---|
| 前端託管 | **Cloudflare Pages**（Git 整合） | 純靜態 SPA，push 即部署；免費方案足夠 |
| 後端對外 | **Cloudflare Tunnel（named tunnel）** | 家用網路免固定 IP、免開 port／改路由器；Martin 維持只綁 `127.0.0.1` |
| 圖磚網域 | 獨立子網域 `tiles.<domain>` | 可單獨設 Cache Rule、WAF；前端與圖磚分離部署 |
| 快取 | Cloudflare edge 快取圖磚 | 大幅降低本機負載；本機斷線時已快取的圖磚仍可用 |
| DB | **不對外** | 只有 Martin（唯讀帳號 `martin_reader`）經 tunnel 曝露 |

不採用：quick tunnel（`trycloudflare.com` 隨機網址、無 SLA）、直接開 port（需固定 IP 與自管 TLS）。

## 3. 前端：Cloudflare Pages

### 3.1 程式修改（`web/`）

1. **正式環境禁止 http 圖磚網址**：Pages 是 https，http 的 `VITE_MARTIN_URL` 會被瀏覽器當 mixed content 擋掉，且錯誤不明顯。
   - `src/config.ts` 的 `parseConfig` 加參數 `isProd: boolean`（呼叫端傳 `import.meta.env.PROD`），`isProd && protocol === 'http:'` 時回傳 error。
   - `src/config.test.ts` 補測試：prod + http → error；prod + https → ok；dev + http → ok。
2. `web/.env.example` 補註解：正式環境由 Pages 環境變數提供 `VITE_MARTIN_URL=https://tiles.<domain>`。
3. 新增 `web/public/_headers`（Pages 自訂標頭）：
   ```
   /assets/*
     Cache-Control: public, max-age=31536000, immutable
   /index.html
     Cache-Control: no-cache
   ```
   `assets/*` 檔名含 hash 可永久快取；`index.html` 每次重新驗證，部署後立即生效。
4. 驗證：`pnpm test`、`pnpm typecheck`、`pnpm build` 通過；`dist/` 內 maplibre worker 為獨立檔（`setWorkerUrl` 機制不變）。

### 3.2 Pages 專案設定（Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git）

| 設定 | 值 |
|---|---|
| Repository | `dino5168/Gis-Martin`，production branch `main` |
| Root directory | `web` |
| Build command | `pnpm install --frozen-lockfile && pnpm build` |
| Output directory | `dist` |
| 環境變數（Production） | `VITE_MARTIN_URL=https://tiles.<domain>`、`NODE_VERSION=22.18.0`、`PNPM_VERSION=10.32.1` |
| Custom domain | `map.<domain>` |

- `VITE_*` 是 **build-time** 變數，改值後必須重新部署。
- Preview 部署（非 main 分支）不在 Martin CORS 白名單內，地圖會載不出圖磚 → 預期行為；需要時再把該 preview 網址加入 CORS。

## 4. 後端：本機 + Cloudflare Tunnel

### 4.1 Martin 設定（`martin/config.yaml`）

只改 CORS，`listen_addresses` **維持 `127.0.0.1:3000`**：

```yaml
cors:
  origin:
    - http://localhost:5173      # 本機開發
    - https://map.<domain>       # Cloudflare Pages 正式網址
```

- Cloudflare 會快取第一個請求的 `Access-Control-Allow-Origin`；白名單只放**一個**正式 origin 可避免快取到錯的 origin。開發用 `localhost:5173` 直連本機 Martin，不經 Cloudflare，不受影響。
- 流程：改 `D:\…\martin\config.yaml` → `Copy-Item` 到 `C:\gis\osm\martin\` → `Restart-Service MartinTiles`（管理員）。

### 4.2 建立 named tunnel（一次性）

```powershell
cloudflared tunnel login                         # 瀏覽器授權，選 <domain>；產生 %USERPROFILE%\.cloudflared\cert.pem
cloudflared tunnel create gis-martin             # 產生 <TUNNEL_ID>.json（tunnel 憑證，等同密碼）
cloudflared tunnel route dns gis-martin tiles.<domain>
```

服務以 LocalSystem 執行，讀不到使用者目錄 → 設定與憑證放 `C:\ProgramData\cloudflared\`（ACL 限 SYSTEM + Administrators），新增設定檔 `config.yml`：

```yaml
tunnel: <TUNNEL_ID>
credentials-file: C:\ProgramData\cloudflared\<TUNNEL_ID>.json
ingress:
  # 只放行唯讀端點：TileJSON（/a,b,c）、圖磚（/a,b,c/z/x/y）、health
  - hostname: tiles.<domain>
    path: ^/(health|[a-z_]+(,[a-z_]+)*(/\d+/\d+/\d+)?)$
    service: http://127.0.0.1:3000
  - service: http_status:404
```

- `path` 白名單讓 `/catalog` 等管理資訊不對外；source 名稱 regex 只允許小寫與底線。
- 原始碼版本放 `D:\…\cloudflared\config.example.yml`（`<TUNNEL_ID>` 以 placeholder 表示），**`*.json` 憑證與 `cert.pem` 不進 git**（`.gitignore` 加 `cloudflared/*.json`、`*.pem`）。
- 安裝服務（管理員）：`cloudflared service install` 後，把服務啟動參數指向 `--config C:\ProgramData\cloudflared\config.yml tunnel run`；啟動類型自動、失敗自動重啟。新增 `martin/service/install-cloudflared-service.ps1`（純 ASCII、idempotent）把以上步驟腳本化。

### 4.3 Cloudflare Zone 設定（Dashboard）

1. **Cache Rule**（Caching → Cache Rules）：`hostname eq "tiles.<domain>"` →
   - Eligible for cache
   - Edge TTL：忽略 origin，**7 天**（資料更新後手動 purge）
   - Browser TTL：**1 小時**
   - Cache key：不含 query string
   - 理由：Martin 無 `Cache-Control`、圖磚路徑無副檔名，Cloudflare 預設不快取。
2. **Rate limiting rule**（Security → WAF）：`tiles.<domain>`，同 IP 每 10 秒 > 600 次 → Block 10 秒（快速平移地圖約 100–200 tile／10 秒，留足餘裕）。
3. SSL/TLS：Full（tunnel 本身已加密，origin 為 localhost http）。
4. 壓縮：Martin 依 `Accept-Encoding` 回傳 gzip，Cloudflare 自動轉發／再壓縮，無需設定。

### 4.4 本機可用性

- 電源設定：關閉睡眠／休眠（`powercfg /change standby-timeout-ac 0`、`hibernate-timeout-ac 0`）。
- 開機自動啟動鏈：`postgresql-x64-17` → `MartinTiles`（已相依）→ `cloudflared`（自動）。Windows Update 重開機後無需登入即恢復。
- 本機離線時：已快取的圖磚照常；未快取的回 Cloudflare 502/530 → 地圖該區空白，屬預期。

## 5. 資料更新流程（補到 CLAUDE.md）

重匯 OSM → 01 → 02 → `Restart-Service MartinTiles` → **Cloudflare purge `tiles.<domain>` 全部快取**（Dashboard → Caching → Purge Everything，或 API `POST /zones/<zone_id>/purge_cache`，token 放 `.env`）。

沒 purge 的話，使用者最多 7 天看到舊圖磚。

## 7. 風險與注意

- **頻寬**：z14 合併圖磚約 450 KB（gzip ~200 KB）。Cache Rule 讓多數請求在 edge 命中，本機上傳頻寬主要消耗在首次瀏覽區域。
- **Cloudflare 條款**：Tunnel + CDN 傳送圖磚（非大量影音）屬一般用途。
- **glyphs 外部相依**：`demotiles.maplibre.org` 仍為外部來源；正式化後可再評估把字型 PBF 放 Pages（`web/public/fonts/`），不在本計畫範圍。
- **tunnel 憑證**（`<TUNNEL_ID>.json`）外洩 = 他人可冒用此 tunnel；ACL 限制、不進 git、不印出內容。
- 與 `SetUp/setup.md`（正式機部署）的關係：本計畫以**開發機本身**當後端。日後搬到正式機，只需在正式機安裝 cloudflared 並以同一 tunnel 憑證執行（或新建 tunnel 改 DNS），前端不需改。
