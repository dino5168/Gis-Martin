
# 需求描述
使用者想要整理出 興趣點的 類別與子類別。
整理成 Table 列在這份文件的下面。

# 興趣點類別與子類別

> 資料來源：PostGIS `osm_taiwan.public.pois`（`taiwan-261112.osm.pbf`），統計日期 2026-11-17。共 257,331 筆，其中 208,072 筆會出圖（含 2026-11-17 開放的公車站牌 49,039 筆）。
>
> - **類別（class）**：OSM 主鍵。`osm2pgsql/taiwan.lua` 依 `amenity → shop → tourism → leisure → historic → office → railway → public_transport` 的順序取**第一個**存在的鍵；同一節點有多個鍵時只歸入最前面那一類。只匯入節點（node），面狀的 POI（如畫成多邊形的學校）不在此表。
> - **子類別（subclass）**：該鍵的值，例如 `amenity=restaurant` → 類別 `amenity`、子類別 `restaurant`。
> - **出圖**：`01_post_import.sql` 的 `minzoom` 規則。`z15` 表示 zoom ≥ 15 才顯示；「僅有名稱者」表示沒有名稱的不顯示；「不出圖」為街道設施、鐵路設施節點等。
